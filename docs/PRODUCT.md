# ORBIT — Product Vision & Overview

## 1. Vision
ORBIT is a personal AI ecosystem designed to unify an individual's goals, active projects, continuous learning, emergent ideas, personal notes, memory, and cognitive graph into a cohesive, intelligent context layer.

Rather than treating tools as disconnected silos (task managers, note apps, LLM chat boxes), ORBIT acts as a centralized personal intelligence operating system that observes cross-domain relationships, synthesizes patterns, and empowers the user to think, plan, and execute with AI augmentation.

## 2. Core Philosophy
- **Personal & Localized Context**: Intelligence tailored to the individual's mental models, focus areas, and evolving projects.
- **Calm & Minimal**: Focused on high-signal clarity, generous whitespace, and minimal noise instead of overwhelming SaaS dashboards.
- **AI-Native from the Ground Up**: Designed around active context synthesis, graph memory, and autonomous agent orchestration.
- **Progressive Disclosure**: Built modularly across targeted phases, preserving code quality and architectural integrity.

## 3. Product Ecosystem Modules
1. **Pulse**: The central overview displaying active signals, synthesized insights, and current focus across all quadrants.
2. **Goals**: Long-term horizons, milestones, and progress alignment.
3. **Projects**: Active workspaces, delivery timelines, and linked resources.
4. **Journal**: Daily reflections, stream-of-consciousness capture, and cognitive logs.
5. **Memory**: Vectorized context engine and durable semantic memory.
6. **Knowledge**: Interactive personal knowledge graph with entity-relationship mapping.
7. **AI Hub & Agents**: Multi-model inference, specialized agent teams, and background task execution.
8. **Personal ML**: Local pattern recognition, habit tracking, and customized synthesis models.
